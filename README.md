# NEXUS GUILD — Gaming Community Landing Page

A fictional, original one-page gaming-community portfolio demo made with plain HTML, CSS and JavaScript. **Not a real community or client project.**

## Quick start (Windows)

1. Extract the ZIP file.
2. Open the `nexus_guild_demo` folder.
3. Double-click `index.html` — it opens in your browser.
4. Test it with a narrow browser window and a full-size window.

There are **no installation commands, packages, or paid services required**. The page uses Google Fonts if an internet connection is available; fallback fonts work offline.

## Features you can try

- The navigation scrolls to real page sections.
- On a narrow screen, the menu button opens and closes the mobile menu.
- The four squad cards filter by category.
- The FAQ questions expand and collapse.
- The 'Find your squad' / 'Join the guild' buttons open a demo modal.
- The form requires a nickname and category before displaying a demo confirmation.
- No form data is sent or saved. This site has **no real back end, signups, paid hosting, or Discord integration**.

## Publish with GitHub Desktop + GitHub Pages

1. In GitHub Desktop: File -> Add local repository -> Choose the `nexus_guild_demo` folder.
2. Choose **Create a Repository Here** if it isn't a Git repository yet.
3. Review changes and commit your work.
4. Click **Publish repository** and uncheck **Keep this code private** only if you're comfortable making this fictional demo public.
5. On GitHub.com, go to the repository's **Settings -> Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**. Select branch `main` and `/ (root)`, then click Save.
7. Once GitHub shows the URL, open it and retest functionality there.
