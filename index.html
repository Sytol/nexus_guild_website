04 / QUESTIONS

GOOD TO KNOW.

Is Nexus Guild a real, active gaming community?+

No. This is a fictional portfolio demonstration showing what a custom gaming landing page could look like. The interface and controls are functional, but there is no live Discord server or registration backend.

Does the join form submit my information?+

No. The form is a front-end demonstration only. It validates required fields and displays a confirmation explaining that nothing was sent or stored.

Can a site like this be customized for a real group?+

Yes. Branding, copy, sections and links can be customized for a real client. Live membership forms, user accounts, event scheduling and integrations require additional development.
